## 一、先搞清一件事：修复前的话不算数

`2026-11-04 18:00` 之前她主动说过 6 句，全部长这样：

```
11-03 13:22  刚刚说心情不好现在好一点了吗。
11-03 13:57  你刚说心情不太好现在好点没。
11-03 14:53  今天心情不好呀那我陪你待着不说别的也行。
11-03 15:26  刚才说心情不好现在好点了吗。
```

**四句都是「刚刚说心情不好」** —— 而那时 `recent_chat` 还只读 `pet` 渠道，
拿到的是 **10-30** 的旧对话。所谓"刚刚"其实在四天前。

这正是这次修复要修的东西之一。所以：**这些旧句子不能拿来判 M6**，
她还没在新代码下真正试过。验收器会自动把 `18:00` 之前的记录标成 `[修复前]` 并排除。

## 二、什么时候能判

需要满足两条：

1. **至少过了 2~3 天真实使用**（不是开着不看，是真跟她说话）；
2. **她至少主动说过几句**（`recent_speak` 非空、且时间在 `11-04 18:00` 之后）。

如果她一句都没主动说，**这不等于 M6 失败** —— 可能是：
- 信息量一直没到阈值（新准则下这很正常，说明真的没活干）；
- 或者 21 点那条节律一直没触发（那时去后台看 `blocked_by` 是什么）。

## 三、怎么跑

### 3.α 只想跑一条命令？用这个

```powershell
& '<venv>\Scripts\python.exe' '<repo>/tools\verify_all.py'
```

它把下面几个工具串起来，**只看一个结论**：

```
结论：2 通过 / 0 需留意 / 0 失败 / 0 跳过 / 1 还没到判定时机
```

退出码：`0` = 没问题 · `1` = 有真失败 · `2` = 有需留意项

**它最重要的设计是区分「还没到判定时机」和「失败」**：
三段对话那条返回"数据不足"时，会归到 `⏳ 还没到判定时机`，
**不算失败、退出码仍是 0**。否则你会被"还没到时候"一直卡住。

参数：
- `--quick` 只跑零成本的两个（数据健康 + 验收矩阵）
- `--with-e2e` 连端到端也跑（需要 8848 + 8898）
- `--json` 机器可读

## 四、它会告诉你什么

输出分三段，每段给两个信息：

| | 素材够不够 | 她说过没有 |
|---|---|---|
| **A**「中间都没歇」 | `longest_gap_min >= 120` | 话里出现「中间/一整天/从早到晚/没歇…」 |
| **B**「我不问了，但我在」 | 长期记忆 > 0 且 owner 画像非空 | 话里出现「不问了/我在/陪你/昨天…」 |
| **C**「你这三天都没来」 | `absent_hours` 能算出 | 话里出现「N 天没/好几天/数着日子…」 |

**「素材够不够」这一栏很重要**：
- 素材不够时判失败是**误判** —— 比如当天最长空档只有 40 分钟，
  她不可能说"中间都没歇"（那是没素材，不是她不想说）。
- 素材够了但没说，才是真的"没喂到点上"。

## 五、判的时候必须记住的两处诚实上限

这两条写在计划第一节 1.3，验收时**别判错**：

**A 的「弄那个」**：系统层不知道你在弄什么，也不该猜。
- 能诚实做到：「你今天从早到晚都没歇过」
- 只在白天你提过时才成立：「都在弄那个」
- → **只说「中间都没歇」也算通过**，不要因为少了"那个"就判失败。

**C 的逐日排比**：原目标「第一天我在想…第二天…」要求每天都真跑过一轮梳理，
而实测停机占 48%，这不可能。
- 已下调为：「你这三天都没来，我数着日子」+ **能说出准确天数**
- → **说出准确天数就算通过**，不要要求逐日排比。

## 六、最后一步：人工过一眼

**词表命中 ≠ 说得自然。** 脚本只做粗筛，最后要你自己看那几句原话像不像人说的。

判断标准（计划第一节 1.4）：

| 什么时候看 | 看什么 |
|---|---|
| 你忙完一天、晚上才找她 | 她有没有提"中间"「一整天」这类**时间感**的话 |
| 第二天早上 | 她有没有接着昨天那句情绪往下说，而不是重新开始 |
| 隔几天回来 | 她知不知道**具体几天**，而不是笼统的"好久不见" |

**三个全中 = M6 达成。中一个算进步，一个都不中说明素材没喂到点上。**

## 七、如果一直不中，查什么（按顺序）

1. **她有没有机会说话** —— 后台「每日梳理期」卡片看 `blocked_by`：
   - `too_early`：还没到 21 点，正常
   - `not_idle`：你还在聊，正常
   - `sleeping`：信息量真的为 0（重复的日子），**这是新准则的正确行为**
   - `probed_declined`：今天已经探过一次，模型说跳过
2. **素材在不在** —— 同上卡片的 `scenario_readiness` 三行
3. **她说了但没送到** —— `recent_speak` 只算 `ok=true`；查 `speak_fail` 事件
4. **长期记忆有没有写进去** —— 体检的 `long_memory_index_ok` / `long_memory_docs`
